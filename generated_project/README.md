# Calculator Web Application

## Project Description
A fully functional calculator web application.

## How to Run the Project
1. Open the `index.html` file in any modern web browser.
2. The calculator interface will load and be ready for use.

## How to Use the Project
1. Input numbers using the on-screen buttons or your keyboard.
2. Select the desired mathematical operation (e.g., addition, subtraction, multiplication, division).
3. Press the equals (`=`) button to see the result displayed on the screen.
4. Use the clear (`C`) button to reset the calculator and start a new calculation.
